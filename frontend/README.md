# EduManage (clean structure)

A production-ready React (Vite + TypeScript) setup with Tailwind v3, dark theme tokens, and Firebase wiring.

## Quick start
```bash
# 1) Install deps
npm i
# 2) Copy env
cp .env.example .env.local   # on Windows: copy .env.example .env.local
# 3) Fill Firebase keys in .env.local
# 4) Run
npm run dev   # http://localhost:3000
```

## Build & Preview
```bash
npm run build
npm run preview  # http://localhost:4173
```

## Firebase Hosting
Build the app then deploy your /dist via Firebase Hosting.
